# 问心大模型智能体平台

问心大模型智能体平台的 Docker 镜像与部署包仓库。智能体平台是问心大模型应用体系的 AI 编排底座，提供大模型应用编排、插件扩展、知识库检索（RAG）、沙箱执行与 Web 控制台能力，支撑十项财经应用中的 AI 起草、AI 审查、智能问答、风险模型在线建模等智能化场景。

## 镜像清单

| 镜像包 | 大小 | 组件角色 |
|---|---|---|
| wenxin-agent-web.tar.gz | 23MB | 问心智能体平台 Web 控制台前端 |
| api.tar | 829MB | 平台 API 后端主服务（应用编排、模型管理、会话接口） |
| daemon.tar | 578MB | 插件守护进程（插件安装、隔离运行与生命周期管理） |
| sandbox.tar | 209MB | 代码执行沙箱（隔离运行 AI 生成的代码） |
| ssrf.tar | 68MB | 安全代理（对外部请求做 SSRF 防护过滤） |
| weaviate.tar | 68MB | 向量数据库（知识库语义检索 / RAG） |
| postgre.tar | 105MB | 平台元数据库（PostgreSQL 15） |
| redis.tar | 12MB | 平台缓存（Redis 6） |
| busybox.tar | 2.2MB | 基础工具镜像（容器内诊断与初始化） |

## 部署步骤

```bash
# 0. 从下方"镜像下载"获取全部镜像包

# 1. 导入全部镜像（按包类型选择命令）
# *.tar 为 docker save 格式：
for f in *.tar; do docker load -i "$f"; done
# *.tar.gz 解压后按内部 tar 再导入：
gunzip wenxin-agent-web.tar.gz && docker load -i wenxin-agent-web.tar

# 2. 初始化平台元数据库（PostgreSQL）与缓存（Redis）

# 3. 编排启动各组件（api、daemon、sandbox、ssrf、weaviate 及 Web 前端）
docker compose up -d

# 4. 访问 Web 控制台完成初始化配置（管理员账号、大模型服务接入地址等）
```

## 环境要求

- Docker 20.10 及以上，内存 ≥ 8GB，磁盘剩余 ≥ 20GB；
- 镜像为 linux/amd64 架构，支持麒麟 V10 等 x86 Linux 与主流服务器环境；
- 需提前准备或使用包内自带的 PostgreSQL（元数据库）与 Redis（缓存）。

## 与其他模块的关系

智能体平台向上为各业务模块提供 AI 能力编排：基础模块仓库中的 AI 大模型服务（hbyunBigModelwen）与各业务模块的 AI 场景（智慧合同的 AI 起草与比对、智慧法务的文件审核与案例检索、穿透式监管的 AI 建模平台等）均可通过智能体平台配置与编排实现。
