# 问心大模型流程引擎 Docker 镜像

问心大模型平台的流程引擎部署仓库。流程引擎是问心大模型**五大引擎**（组织、角色、流程、表单、规则）之一，基于 Flowable 工作流内核，为各业务模块的审批流转（合同审批、风险审批、审计文书审批、整改通知下达等）提供流程编排与任务驱动能力。本仓库存放流程引擎**管理端前端构建产物**及部署启动说明。

## 启动方式

### 方式一：独立部署管理端前端

解压 `dist.zip`，由 Nginx 等静态服务器托管 `dist/` 目录，并将 API 请求反向代理到流程引擎工作流管理端服务（默认端口 **31000**）：

```nginx
server {
    listen 80;
    root /usr/share/nginx/html;   # dist/ 解压目录
    location / {
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    location /api/ {
        proxy_pass http://127.0.0.1:31000/;   # 工作流管理端服务地址
    }
}
```

### 方式二：纳入微服务 Docker 离线部署包（推荐）

管理端与微服务离线部署包配套使用。部署包含 13 个服务镜像（nacos-server、gateway、oauth、system、visualdev、**flowable（流程引擎，端口 30004）**、file、message、scheduletask、permission、visualdata、app、extend）及可选的 **workflow 工作流管理端（端口 31000）**。

**1. 环境检查**

| 检查项 | 要求 | 检查命令 |
|---|---|---|
| Docker | 20.10 及以上且已启动 | `docker version` |
| 磁盘 | 剩余 ≥ 20GB | `df -h` |
| 内存 | ≥ 8GB | `free -h` |
| 端口 | 30000、30001~30012、30019、30099 未占用；启用管理端再加 31000 | `ss -tlnp` |

**2. 准备数据库与 Redis**

- Nacos 专用库：用对应数据库类型的 Nacos 初始化脚本建表，并包含 `nacos/nacos` 管理账号；
- 业务库与工作流管理端专用库：执行业务初始化 SQL；
- Redis 一个（业务缓存必须）。
- 数据库支持：达梦 DM / 人大金仓 KingbaseES / MySQL / Oracle / SQLServer / PostgreSQL。

**3. 交互式配置（写入数据库连接等信息）**

```bash
# Linux（麒麟 V10）/ macOS
cd deploy/docker/nacos-config-tools && chmod +x setup.sh && ./setup.sh

# Windows（PowerShell）
cd deploy\docker\nacos-config-tools
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

脚本依次询问 Nacos 库、workflow 库（达梦/Oracle 需填模式名）、业务库、Redis 连接信息，并自动写入 `docker/nacos-conf/application.properties`、根目录 `application-dev.yml`（workflow 专用）与 `datasource.yaml`。

**4. 一键部署**

```bash
cd deploy
./install.sh    # 导入全部镜像 → 启动 Nacos → 导入业务配置 → 启动全部微服务
```

Windows 可分步执行：`docker load` 导入全部 tar 镜像 → `docker compose up -d nacos-server` → `config-import.ps1` 导入配置 → `docker compose up -d`。

**5. 启动工作流管理端（流程引擎）**

```bash
cd deploy/docker
docker compose --profile workflow up -d workflow
```

**6. 验证启动**

```bash
docker compose ps                 # 全部服务 Up/running
curl http://部署机IP:30000/       # 网关就绪（任意 HTTP 响应即可）
# 浏览器打开 http://部署机IP:30099/nacos（nacos/nacos）查看服务列表
# 工作流管理端: http://部署机IP:31000
```

以上全部通过即部署完成。若需调整对外域名，修改 `system-config.yaml` 中的 `ApiDomain/FrontDomain/AppDomain` 后重新 `config-import` 并 `docker compose restart`。

## 常见问题

| 现象 | 处理 |
|---|---|
| Nacos 反复重启 | `docker logs nacos-server`：核对数据库连接；`Table doesn't exist` 表示表结构未初始化 |
| 服务一直 Restarting | 等 Nacos 就绪；核对 `datasource.yaml` 后重新导入配置并重启 |
| 配置导入报 403 | Nacos 库缺 `nacos` 账号或 ADMIN 角色，按初始化 SQL 补齐 |
| 端口被占用 | 改 `docker-compose.yml` 端口映射冒号左侧后 `up -d` 重建 |
| 管理端页面打开但接口报错 | 确认 `application-dev.yml` 数据库连接正确，且 workflow 容器已启动（31000） |

## 与其他模块的关系

流程引擎（flowable，30004）作为基础服务随部署包启动，各业务模块的审批流（合同审批、整改通知、审计文书流转等）通过工作流管理端（workflow，31000）建模编排；前端服务与管理端均通过网关（30000）访问后端接口。
